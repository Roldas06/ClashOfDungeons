# Clash of Dungeons

## Apie žaidimą
<p align="left">
  "Clash of Dungeons" yra tamsus 2D platforminis žaidimas, įsikūręs giliai niūriuose požemiuose, pripildytuose mirtinų spąstų, iššūkių keliančių parkūrų ir pavojingų priešų. Tyrinėk paslaptingus požemius, surink visus 3 paslėptus raktus ir išgyvenk pakankamai ilgai, kad atrakintum požemio vartus ir pabėgtum į kitą iššūkį. Kiekvienas lygis išbando jūsų tikslumą, laiką ir drąsą pasaulyje, kuriame už kiekvieno kampo tyko pavojus.
</p>
